Leitor aguardando aproximação

O leitor físico é executado pelo programa leitor.js no computador conectado ao ESP8266. Esta tela consulta o banco de dados e atualiza os registros após cada leitura.

Importante para a leituraMantenha o servidor e o processo RFID abertos em terminais separados. Feche o Monitor Serial da Arduino IDE antes de iniciar o leitor.js. O status desta página não confirma, sozinho, que o RC522 está lendo tags.
